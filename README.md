This work contains all my work on asynchronous (self-study) courses. Although some courses did have pedagogical applications later on (AP exams), the vast majority were simply done for projects that require such material or for the fun of it. As such, my work is *very* personalized—I don't prioritize clarity or rigor as much as I should. If you have questions please send me an email at pablo.silvalizarraga@gmail.com 

Note: I included a LICENSE file for courses that require attribution among other legal stuff.
